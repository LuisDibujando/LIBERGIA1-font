**LIBERGIA1** es un **Reserved Font Name**.

Las versiones modificadas de la tipografía no deben utilizar el nombre principal `LIBERGIA1` salvo autorización expresa del titular del copyright.

## Uso en LIBERGIA

La tipografía puede integrarse en la aplicación LIBERGIA como fuente web mediante `@font-face`, por ejemplo:

```css
@font-face {
  font-family: "LIBERGIA1";
  src: url("fonts/LIBERGIA1.woff2") format("woff2");
  font-style: normal;
  font-weight: normal;
}
```

## Nota sobre modificaciones

Si una persona modifica la tipografía y redistribuye esa versión, deberá mantenerla bajo OFL 1.1 y utilizar un nombre diferente si la modificación cambia la fuente original, salvo autorización expresa para usar el Reserved Font Name.
